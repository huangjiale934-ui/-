# 香港強積金數據平台（MPF Data Dashboard）

451 只強積金成分基金的淨值、自算回報指標、十大持倉與投資分布一站式查詢平台。
純前端 + 靜態 JSON（GitHub Pages 托管），數據全部來自發行人官網與積金局基金平台，100% 官方渠道。

## 線上地址

- GitHub Pages：https://huangjiale934-ui.github.io/-/
- （原 Node 版線上：https://mpf-data.app.workbuddy.host/ ）

## 功能

- 資料庫：451 只基金查詢/篩選/三態排序/列配置/導出 CSV 與 xlsx，簡繁英三語
- 排名榜：36 個維度 / 6 組，含本站自算淨值指標（日/周/月/年初/1年/3年/5年/回撤）
- 對比：最多 6 只基金走勢對比、發行人平均 vs 恒指
- 定投計算器：前端本地計算（份額累加法，支持缺口提示/期末截斷/權重校驗）
- 詳情彈窗：十大持倉、投資分布、自算指標、過期徽標

## 架構

```
public/          前端（原生 JS，無框架）
  api-adapter.js fetch 攔截層：/api/* → api/*.json（Pages 靜態托管適配）
server.js        本地開發/驗證用 Node 服務（提供 /api/* 動態接口，與靜態產物逐字節一致）
data/            數據（各發行人官網抓取產物，每日更新）
  hist/          450 只日度淨值序列
tools/           抓取/解析/校驗/構建腳本
  build-static.js  靜態化構建：起真實 server 拉取全部 API 響應落盤（邏輯零漂移）
  check-continuity.js  歷史連續性掃描（HSI 交易日歷）
.github/workflows/  GitHub Actions（構建部署 + 每日數據更新）
```

## 每日自動更新

1. GitHub Actions 定時抓取（見 `.github/workflows/`），抓取失敗時保留上次數據並標記；
2. 數據變更自動 commit 並觸發重新部署。

## 數據來源與口徑

- 業績/規模/風險：積金局「強積金基金平台」（月度）
- 日度淨值：各發行人官網接口/便覽 PDF（第一優先）；官網無數據的僅 AMTD 16 只採用 etnet 環富通
- 十大持倉/投資分布：發行人官方便覽 PDF 原件（月報/季報）
- 本站僅做官方數字匯總，不做推算、加權或補全；歷史序列如實呈現官網發布
